# Pong Game

## Description
The Pong Game is a classic arcade game where two players control paddles and try to hit a ball back and forth. The objective is to score points by getting the ball past the opponent's paddle.

## Features
- Single-player and multiplayer modes
- Adjustable game difficulty
- Sound effects and music
- Score tracking with a scoreboard
- User-friendly interface

## How to Play
1. Launch the game application.
2. Choose between single-player or multiplayer mode.
3. Use the designated controls to move your paddle (detailed below).
4. Try to hit the ball and prevent it from going past your paddle.
5. The game continues until a player reaches the winning score.

## Controls
- **Player 1 (Left paddle)**: Use the `W` key to move up and the `S` key to move down.
- **Player 2 (Right paddle)**: Use the `Up` arrow key to move up and the `Down` arrow key to move down.
- **Pause**: Press the `P` key to pause the game.

## Technical Details
- Developed using JavaScript and HTML5.
- Utilizes the Canvas API for rendering graphics.
- Employs event listeners for user input.
- Scoring logic is handled in real-time to provide immediate feedback to players.

## Installation
1. Clone the repository: `git clone https://github.com/anirudh111391-max/pong-game.git`
2. Open the `index.html` file in a web browser to start playing.
